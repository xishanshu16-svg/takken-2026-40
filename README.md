# 2026宅建40点突破AI

2026年度宅地建物取引士試験で40点を目指す、日本語の静的学習アプリです。ログイン不要、フレームワーク・外部AI API・実行時の外部ライブラリ不要。的中・40点・合格を保証する教材ではありません。

**公開アプリ:** https://takken-2026-40.pages.dev/  
**分析レポート:** https://takken-2026-40.pages.dev/reports/study-report.html

## 収録内容

- オリジナル予想100問（本試験50問＋追加50問）、全400肢に独立した解説
- 本試験50問・120分。絶対時刻によるタイマー、自動保存、任意移動、未回答移動、時間切れ自動採点
- 本試験の配置：権利1–14、法令15–22、税23–25、業法26–45、その他46–50
- 分野別演習、誤答再挑戦、誤答回数、お気に入り、重要論点、直前60分チェック
- 分野別累計正答率、40点目標、模試得点推移、前回差、学習履歴
- localStorage保存、JSONバックアップと復元、スマートフォン・キーボード対応

## 法令・教材について

法令基準日は **2026年4月1日**、公式情報の照合日は **2026年10月18日**。試験の基準日は不動産適正取引推進機構の[試験案内](https://moushikomi.retio.or.jp/)で確認しています。

提供されたPDF9冊（計644ページ）を分野別に確認しました。元PDF本文・画像はリポジトリにもサイトにも再配布していません。問題は新規作成し、各問の `pdfReferences` に関連する **PDFの物理ページ番号（1起算）** を記録しています。冊子に印刷されたページ番号とは区別してください。各問の `sources` から公式資料を確認できます。

分析の全頁索引・教材に記載された過去年・改正時の注意は `reports/*-analysis.json`、統合記録は `reports/analysis.json` にあります。教材内の掲載回数は本試験全体の頻度ではありません。A/B/Cは学習優先度で、出題確率ではありません。採用理由は各問の `rationale`、法令は `law`・`articles` にあります。

取得税等には2026年改正で古い教材記述と差が生じる事項があるため、根拠が十分な設問を採用しています。過去の出題年を推定して補っていません。統計問題は対象年・年度と公表時点を明記しています。

## ローカルで動かす

Node.js 22以降とPython 3を用意します。npm依存パッケージはありません。

```sh
cd takken-2026
npm run build
npm run serve
```

ブラウザで `http://localhost:8765` を開きます。`index.html` の直接ダブルクリック（file://）ではJSONを読み込めないブラウザがあります。HTTP経由で開いてください。

## 問題を修正・追加する

1. `data/brokerage.json`（宅建業法）、`data/civil.json`（権利）、`data/regulations-tax.json`（法令・税その他）を修正します。
2. `id` は変更しないでください。履歴はIDで紐付けています。別問題への置き換えは新しいIDを発行します。
3. 正解は `answer: 1〜4`、選択肢は `options`、各肢解説は同順の `explanations` です。公式根拠と正解が一つになる条件を再確認してください。
4. `npm run build` を実行します。統合JSON・A優先度の暗記項目を再生成し、テスト・構造検証の後で公開用 `dist/` を作ります。
5. ブラウザで動作と法的内容を確認し、GitHubへ反映します。

構造テストは法的正解を証明するものではありません。内容を変えたら公式法令・施行日・全肢・採用理由を人の判断で再確認してください。未確認問題は `verified: true` にしないでください。検証は未確認問題を含むビルドを拒否します。

```sh
git add .
git commit -m "Update verified study questions"
git push origin main
```

## Cloudflare Pages設定

推奨はGitHub連携による自動公開です。

| 項目 | 値 |
|---|---|
| リポジトリ | `xishanshu16-svg/takken-2026-40` |
| 本番ブランチ | `main` |
| フレームワーク | None |
| ビルドコマンド | `npm run build` |
| ビルド出力ディレクトリ | `dist` |

| 環境変数 | 不要（ビルド環境はNode.js 22以降） |

新規設定はCloudflareの Workers & Pages → Create application → Pages → Import an existing Git repositoryで上記を設定します。DNS・独自ドメイン変更は不要です。公開に関する実行結果・検証は別添の納品報告を参照してください。設定値を記しただけで公開済みとは扱いません。

Git連携が使えない場合の手動公開は以下です。先に `npm run build` を成功させてください。

```sh
npx wrangler login
npx wrangler pages project create takken-2026-40 --production-branch main
npx wrangler pages deploy dist --project-name takken-2026-40 --branch main
```

Git連携プロジェクトとDirect Uploadでは切替に制約があるため、先に方式を選びます。[Cloudflare公式](https://developers.cloudflare.com/pages/configuration/git-integration/)参照。

## 保存とプライバシー

- 保存キーは `takken2026:v1`。問題データと履歴は分離されています。
- 回答、模試結果、誤答回数、直近の正誤、お気に入り、演習途中状態、進行中模試の絶対期限を保存します。
- 問題更新後も同じIDなら履歴が残ります。既存IDを別論点に使い回さないでください。
- 保存拒否・容量不足・破損時は画面上で通知します。プライベートブラウズやデータ削除では履歴が失われることがあります。
- 学習履歴画面でJSONを保存し、別端末の同画面から復元できます。復元時は確認後に履歴を置き換えます。
- オフライン対応は保証していません。初回・再読込時は問題JSONの取得が必要です。
- 「AI」は教材制作を指します。アプリで外部AIを呼び出す機能はありません。学習提案は端末内の正答率に基づきます。

## 検証と設計

```sh
npm test
npm run validate
```

自動テストは採点、目標点の境界、タイマーの絶対期限、誤答後の再挑戦、保存復元、保存失敗を確認します。データ検証は100問、配置、4択、全400解説、正解番号、関連PDFのページ範囲、出典、確認フラグ、重複と正解位置を検査します。

アプリは `js/app.js`（画面・操作）、`quiz.js`（セッション）、`timer.js`、`scoring.js`、`storage.js`、`analytics.js` に分離しています。CSPを `_headers` で設定し、外部スクリプト・通信を使いません。公開先は `dist/` のみで、開発用JSON・テスト・元PDF・認証情報を含みません。

法的な内容は学習用で、個別の取引に関する専門家の助言ではありません。誤りに気付いた場合は該当IDと根拠を記録し、修正後に同じ検証を繰り返してください。
